# 黄金在线 · 产品文档（product）

> 版本：v1.0 ｜ 日期：2026-11-19 ｜ 上游依据：[requirements.md](requirements.md)

## 1. 产品定位

一款面向个人黄金基金投资者的**单页静态看板**：看宏观（金价、美联储利率、中国国债）、看自选基金净值、算自己的持仓盈亏与补仓模拟。无登录、无后端、数据本地化。

## 2. 页面结构

单页应用，顶部导航切换三个分区（Tab），默认进入「宏观指数」：

```
┌──────────────────────────────────────────────┐
│  黄金在线   [宏观指数] [自选基金] [持仓盈亏]     │
├──────────────────────────────────────────────┤
│  分区内容区（图表 + 控件）                      │
├──────────────────────────────────────────────┤
│  页脚：数据来源标注 · 免责声明 (FR-04)          │
└──────────────────────────────────────────────┘
```

## 3. 模块详细设计

### 3.1 宏观指数（Tab 1）

| 元素 | 说明 |
|---|---|
| 图表 ×3 | ① 黄金价格（默认 COMEX 主力 USD/oz，可选上金所黄金9999 元/克）② 美联储利率（EFFR，%）③ 中国 10 年期国债收益率（%，10Y 数据自 2023-05 起） |
| 图型 | 折线图（利率可用阶梯线 step 更贴近利率台阶变动） |
| 时间范围 | 1M / 3M / 6M / 1Y / 3Y / 5Y / MAX 按钮组，三图共用或各图独立（各图独立） |
| 悬浮提示 | 日期 + 数值 + 单位 |
| 来源标注 | 每图左下角小字注明数据源 |
| 异常态 | 某源失败：该图区域显示「数据源暂时不可用（来源：×××）」，不影响另两图 |

### 3.2 自选基金（Tab 2）——2026-11-19 修订：默认看板 + 个人基金板块

| 元素 | 说明 |
|---|---|
| 查询框 | 页面顶部：输入 6 位基金代码，回车/点击「查询」，结果以看板卡片展示在页首 |
| 黄金基金看板 | 默认展示 4 只：华安黄金ETF 518880、华安黄金ETF联接A 000216、华安黄金ETF联接C 000217、华夏黄金ETF联接C 008702（用户指定追加） |
| 基金看板卡片 | 名称/代码、最新净值与日涨跌幅（涨红跌绿）、时间范围切换（同 3.1）；折线数据可切换：单位净值（无分红基金自动省略重合的累计净值线）或日涨跌（% 曲线，含 0 基线） |
| 「保存/移出」按钮 | 每张卡片右上角；保存到「个人基金」板块，已保存则显示「移出」 |
| 个人基金板块 | 位于黄金基金看板上方（2026-11-19 调整）；localStorage `hjzx.watchlist` 持久化，下次打开自动展示、无需重复查询；空态显示引导文案 |

**交互流程**：打开页面即渲染默认看板与个人基金 → 查询任意基金 → 点「保存」进入个人基金。代码不存在/网络失败 → 卡片内错误提示；格式非法 → 查询框下方红色提示。

### 3.3 持仓盈亏（Tab 3）

**持仓录入表单**：

| 字段 | 必填 | 校验 |
|---|---|---|
| 基金（从自选选择，或直接输入代码） | 是 | 必须能拉到净值序列 |
| 投入本金（元） | 是 | > 0 的数字 |
| 持有成本单价（元/份） | 是 | > 0 的数字 |
| 建仓日期 | 否 | 合法日期；缺省时盈亏曲线从净值序列可用起点开始，并标注「模拟起点」 |

**核心计算**（口径见 requirements FR-03）：

```
份额 = 投入本金 ÷ 持有成本单价
浮动盈亏(日 d) = 总份额 × 净值(d) − 总投入
盈亏率(日 d) = 浮动盈亏 ÷ 总投入
补仓后新成本单价 = (原本金 + 补仓金额) ÷ (原份额 + 补仓金额 ÷ 补仓日净值)
```

**输出图表**：
- **盈亏变化线**：按净值序列逐日计算，正盈亏绿色/负盈亏红色（面积图辅助观察）；
- **持有成本单价变化线**：水平线段，补仓发生日出现阶跃下降；
- 两线同图（双序列）或上下两图（实现时取更清晰者），时间范围可切换。

**补仓记录**：表格列出每条补仓（日期、金额、补仓时净值、新增份额、补仓后成本单价），支持逐条删除并即时重算。补仓日期默认最新净值日，可改。

**数据持久化**：localStorage 单 key 存储（见 §4），含持仓与补仓明细；提供「清空持仓数据」入口（二次确认）。

**指标卡片**（图表上方）：当前净值、总份额、总投入、当前市值、浮动盈亏（额与率）、当前成本单价。

### 3.4 页脚（全局）

数据来源与更新频率说明；免责声明「数据仅供参考，不构成投资建议」。

## 4. 数据设计

### 4.1 指数/净值序列（运行时内存）

```json
{
  "code": "101.GC00Y|US_EFFR|171.CN10Y|<基金6位代码>",
  "name": "COMEX黄金",
  "source": "eastmoney-kline | nyfed-effr | fund-pingzhongdata",
  "points": [{ "date": "2026-01-02", "value": 2645.30 }]
}
```

### 4.2 localStorage

| Key | 内容 |
|---|---|
| `hjzx.watchlist` | 个人基金数组 `[{ code, name }]` |
| `hjzx.cache.*` | 行情/净值当日缓存（M3 起启用，见 requirements NFR-07；points 存 `[date, value]` 紧凑格式） |
| `hjzx.position` | 持仓对象 `{ fundCode, principal, costPrice, openedAt, topups: [{ date, amount }] }` |
| `hjzx.settings` | 预留（默认时间范围等） |

### 4.3 数据快照（降级方案，若启用）

`data/<series>.json`，结构同 §4.1，由本地脚本 `scripts/fetch_*.py` 加系统定时任务每日生成提交。

## 5. 视觉与风格

- **视觉方案（2026-11-19 用户选定：方案 A · Apple 经典，示意页 design/mock-a.html）**：严肃冷静，Apple 取色——浅色基底 #F5F5F7 / 卡片 #FFFFFF / Apple 蓝 #0071E3；深色基底 #0D0D0F / 卡片 #1C1C1E / #0A84FF；涨跌色用系统红/绿（涨红跌绿不变）；图表线条色随主题自动适配；
- **亮暗色模式**：默认跟随系统（prefers-color-scheme），顶栏右上角圆形按钮手动切换，手动选择后记忆（localStorage `hjzx.theme`），未手动设定时系统切换自动生效；主题变化时全部图表自动重绘；
- 布局：卡片分区、14px 圆角、毛玻璃顶栏、极淡阴影；
- 移动端：三 Tab 折叠为顶部横滑导航，图表自适应宽度。

## 6. 异常与边界

| 场景 | 处理 |
|---|---|
| 基金代码不存在 | 提示「未找到该基金，请检查代码」 |
| 数据接口全部失败 | 各模块独立提示，页面骨架仍可用 |
| 持仓净值区间早于建仓日期 | 曲线从两者较晚者起画 |
| 补仓日期早于建仓日期 | 表单校验拦截并提示 |
| 本金/成本输入非法 | 输入框即时红框 + 提示 |
| 清空持仓 | 二次确认弹层 |

## 7. 版本规划

- **v1.0（本路线图范围）**：§3 全部四个模块 + GitHub 仓库托管 / GitHub Pages 上线；
- **v1.1（已确认规划，2026-11-19 用户指定，M5 完成后启动）**：
  - **截图 OCR 导入持仓**（用户指定，含识别入口；**已提前实现，2026-11-19，M5 之前完成**）：
    - **入口**：持仓盈亏页签「持仓录入」卡片新增「导入持仓截图」按钮（后续可复用至自选基金查询卡片）；
    - **说明文案**：入口旁提示「截图需包含基金代码（如页面顶部『008702』字样完整可见），未识别到时代码需手动填写」；
    - **流程**：选择/粘贴截图 → 本地 OCR（Tesseract.js，模型文件本地化至 `vendor/`，数据不出浏览器）→ 识别字段：基金代码、持有份额、持有成本单价、持有金额、持有收益 → 自动填入持仓表单 → **用户确认后手动保存**（OCR 数字可能错漏，禁止直接写库）；
    - **待确认金额**（如支付宝 T+1 未确认份额）不参与计算，份额确认后以补仓方式录入；
    - **实现要点**：`js/ocr/position-ocr.js`；本金优先用「持有金额 − 持有收益」反推（与支付宝账本逐位一致），兑底用「份额 × 成本单价」；标签行与数值行分行时按标签序号跨行提取；负号多字形（− – —）统一；代码字段在截图顶部被裁切时无法识别（实测样例即如此），需人工填写；
  - **支付宝/天天基金交易对账单导入**：纯前端解析对账单文件（CSV/XLSX），逐笔重建份额、摊薄成本、逐日盈亏，支持定投多笔；数据不出本地；
  - 其他候选：多持仓组合汇总、中国国债多期限、黄金与利率/国债相关性对比图、深色模式；
- **v2.0 候选**：场内 ETF 行情、海外资产、持仓数据导出。
