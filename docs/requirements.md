# 黄金在线 · 需求文档（requirements）

> 版本：v1.0 ｜ 日期：2026-11-19 ｜ 状态：已确认（用户已核对数据源、品种范围、部署形态、持仓语义四项关键决策）

## 1. 项目背景与目标

用户是个人黄金基金投资者，希望有一个轻量网页，集中查看：

1. 黄金价格指数走势；
2. 美联储利率走势；
3. 中国国债收益率走势；
4. 自己已投资的基金/金融产品的价格（净值）走势；
5. 自身持仓的盈亏变化，并支持模拟补仓对持有成本单价与盈亏的影响。

产品为**纯静态网页**，代码托管 GitHub（alotslost/Gold-Online），通过 GitHub Pages 发布（2026-11-19 用户最终指定），数据来自**免费公开数据源**，持仓数据只存在浏览器本地，不上传服务器。

## 2. 用户与场景

| 项 | 说明 |
|---|---|
| 目标用户 | 用户本人（个人投资者），无需多用户/登录体系 |
| 使用场景 | 打开网页快速查看宏观行情与自己持仓的盈亏；补仓决策前模拟补仓后的成本单价与盈亏变化 |
| 使用设备 | 桌面浏览器为主，需兼容移动端浏览 |

## 3. 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 数据来源 | 免费公开数据源（候选源见第 5 节，可行性在 M1 验证后定案） |
| 品种范围 | 国内场外基金为主（6 位基金代码），不做场内股票/ETF 行情、不做海外资产 |
| 部署形态 | GitHub 仓库 + GitHub Pages 静态托管，可在线访问 |
| 持仓语义 | 「持仓总额」= **投入本金（元）**；份额 = 本金 ÷ 持有成本单价 |

## 4. 功能需求（FR）

### FR-01 宏观指数看板
- 展示三类指数的时间序列折线图，每类一张图：
  - **黄金价格指数**：黄金价格走势（默认上金所黄金9999 元/克，标题右侧可切 COMEX 黄金主力 USD/oz；伦敦金现接口无数据；默认单位为用户指定，2026-11-19）；
  - **美联储利率**：美国联邦基金有效利率 EFFR（%）（M1 实测调整：FRED 被浏览器 CORS 拦截，改用纽约联储官方 API，口径由目标区间上限改为 EFFR）；
  - **中国国债指数**：中国 10 年期国债收益率（%），可扩展多期限。
- 每张图支持常用时间范围切换：1M / 3M / 6M / 1Y / 3Y / 5Y / MAX。
- 悬浮显示具体日期与数值；数据来源在图下角标注。
- **验收标准**：三类图表均可渲染且时间范围切换生效；无数据/接口失败时给出明确错误提示而非空白。

### FR-02 自选基金（净值展示）——2026-11-19 随 M3 需求修订
- 页面默认直接展示**「黄金基金看板」**：华安黄金ETF（518880）、华安黄金ETF联接A（000216）、华安黄金ETF联接C（000217）、华夏黄金ETF联接C（008702，用户指定追加）。
- 顶部查询框：输入 6 位国内场外基金代码查询任意基金，查询结果以看板卡片展示在页首。
- 每张看板卡片：名称/代码、最新净值与日涨跌幅、单位净值 + 累计净值双线图、时间范围切换（与 FR-01 一致）。
- 「黄金基金看板」标题右侧提供**折线数据切换标签**（用户追加，2026-11-19）：「单位净值」（默认，无分红的基金自动省略重合的累计净值线）与「日涨跌」（每日涨跌幅 % 曲线，y 轴含 0 基线），作用于该板块全部卡片。
- 每张卡片提供**「保存/移出」**按钮：保存到页内**「个人基金」板块**（localStorage `hjzx.watchlist` 持久化），下次打开自动展示、无需重复查询。
- **验收标准**：默认看板自动渲染且含 008702；有效代码可正确渲染净值图；输入无效代码有明确提示；保存/移出后刷新页面状态保持。

### FR-03 持仓盈亏模拟
- 用户针对某只已选基金录入持仓：
  - 必填：**投入本金（元）**、**持有成本单价（元/份）**；
  - 可选：**建仓日期**（用于限定盈亏曲线起点）。
- 系统按 `份额 = 投入本金 ÷ 持有成本单价` 推算份额，结合该基金历史净值序列绘制两条折线：
  1. **持有成本单价变化线**；
  2. **盈亏变化线**（金额，浮动盈亏 = 总份额 × 当日净值 − 总投入；可另示盈亏率）。
- 支持**补仓模拟与补仓记录**：输入补仓金额（元），可指定补仓日期（默认为最新净值日）：
  - 新增份额 = 补仓金额 ÷ 补仓日净值；
  - 新成本单价 = （原本金 + 补仓金额）÷（原份额 + 新增份额）；
  - 补仓后曲线即时重算：成本单价出现阶跃下降，盈亏线随之变化。
- 支持录入多条补仓记录，并可删除单条记录后重算。
- 持仓与补仓数据仅存 localStorage，提供清空入口。
- **验收标准**：给定一组本金/成本/净值样例，份额、成本单价、盈亏三项计算结果与手工核算一致；补仓后成本单价下降幅度与手算一致；删除补仓记录后恢复原值。

### FR-04 数据来源与免责说明
- 页面固定位置（页脚）标注各数据来源与更新频率，并注明「数据仅供参考，不构成投资建议」。

## 5. 数据需求（候选源，M1 实测定案）

| 数据 | 候选源 | 接入方式 | 更新粒度 | 降级方案 |
|---|---|---|---|---|
| 基金净值（历史+估值） | 天天基金 `pingzhongdata/{code}.js`、`fundgz.1234567.com.cn/js/{code}.js` | `<script>` 注入（JSONP 风格，天然免跨域） | 日 | 无需 |
| 黄金价格 | 东方财富行情 K 线接口（伦敦金现/COMEX 金） | JSONP 回调参数 | 日 | 本地/定时任务快照 `data/*.json` |
| 美联储利率 | FRED `fredgraph.csv`（DFF / DFEDTARU） | fetch（FRED CSV 一般允许 CORS） | 日/事件 | 同上 |
| 中国国债收益率 | 东方财富国债收益率接口 / 中债官网 | 待 POC | 日 | 同上（首选本地定时快照） |

- 若某源浏览器直连不可行（CORS 拒绝），统一降级为**仓库内静态 JSON 快照**：由本地脚本或定时任务抓取生成、提交入库，前端只读本仓库文件——保证静态托管上稳定可用。
- 所有接口与快照字段统一映射为内部数据结构：`{ code, name, points: [{ date, value }] }`。
- **M1 实测结果（2026-11-19）**：四源均已定案且浏览器直连可用，快照降级暂不启用；最终接入方式以 [roadmap.md §2](roadmap.md) 为准。

## 6. 非功能需求（NFR）

| 编号 | 要求 |
|---|---|
| NFR-01 | 纯静态站点，无自建后端；代码托管 GitHub，发布于 GitHub Pages |
| NFR-02 | 无构建工具链或仅极简工具链；第三方库（ECharts）本地化引入，不依赖运行时 CDN |
| NFR-03 | 持仓等个人数据仅存 localStorage，不采集、不上传 |
| NFR-04 | 桌面优先，移动端可正常浏览（响应式布局） |
| NFR-05 | 首屏加载与图表渲染流畅；任一数据源失败不影响其他模块独立可用 |
| NFR-06 | 接口失败/空数据/非法输入均有用户可见的提示与兜底 |
| NFR-07 | 行情/净值数据当日 localStorage 缓存（`hjzx.cache.*`，2026-11-19 用户追加）：同一天内刷新/重开页面不发网络请求，防数据源 IP 风控；每卡片提供「刷新」按钮强制拉取；接口失败时回退最近缓存保证可用 |

## 7. 范围外（v1.0 不做）

- 交易下单、账户对接、支付；
- 多用户与登录鉴权；
- 场内 ETF/股票实时行情、海外资产；
- 盘中秒级行情推送；
- 移动 App / 小程序。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 免费接口 CORS 限制或改版 | JSONP 优先；不可行的源走本地定时快照降级；M1 统一实测并记录结论 |
| 数据准确性（接口字段口径变化） | 图表统一标注来源；关键数值计算（FR-03）配对账样例 |
| GitHub Pages 免费版限制 | 需公开仓库；push 到发布分支自动发布，无需手动操作；页面为纯静态无敏感内容 |
