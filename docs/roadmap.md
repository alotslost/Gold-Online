## 0. 技术决策（已定）

| 项 | 决策 |
|---|---|
| 架构 | 纯静态站点，无后端、无框架构建链 |
| 前端 | 原生 HTML + CSS + JavaScript（ES Modules） |
| 图表 | Apache ECharts，本地化到 `vendor/`，不依赖运行时 CDN |
| 本地预览 | 仓库根目录执行 `python3 -m http.server 8000`，访问 `http://localhost:8000`（ES Modules 必须走 http，不能 file:// 直开） |
| 部署 | Gitee Pages（2026-11-19 用户指定，原 GitHub Pages；免费版每次推送后需手动「更新」发布） |
| 个人数据 | localStorage，key 前缀 `hjzx.` |

## 3. 执行纪律（每轮开发必守）

1. **会话入口**：先读 `agent.md`，再读本文件找最靠前的未完成任务；只读完成任务所需的文档章节，节省上下文。
2. **完成即记录**：功能通过验证后，立即更新 [completed.md](completed.md)（追加条目）并勾选本文件任务；中断时在本文件标注 `[~]` 与现状。
3. **改动前读现状**：改任何文件前先读其当前内容；动手前跑一次既有校验（本地服务器可打开、控制台无报错）记基线。
4. **同层校验**：改 JS 后刷新页面实测交互与控制台；改计算逻辑必跑对账样例；未实际验证的改动不得标记完成。
5. **如实报告**：每轮结束说明做了什么、验证了什么、遗留什么。
